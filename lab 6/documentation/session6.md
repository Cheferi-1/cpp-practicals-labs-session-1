# SESSION 6: INTEGRATED C++ PROJECT

**Planned date:** 10 November 2026  
**Project:** Student Academic Management System  
**Status:** Prepared - testing pending

## 1. Project objective

Develop a menu-driven C++ program that stores and manages student academic records.

## 2. Student information

Each student record contains:
- Student ID
- Student name
- Department
- Score

## 3. System functions

1. Add a student.
2. Display all student records.
3. Search for a student using the ID.
4. Update a student's score.
5. Delete a student record.
6. Exit the program.

## 4. C++ concepts used

- Structures
- Arrays
- Functions
- Loops
- Conditional statements
- Switch statements
- Strings

## 5. Suggested tests

| Test | Action | Expected result |
|---|---|---|
| 1 | Add a student with ID 101 and score 75 | Student added |
| 2 | Display students | Student 101 appears |
| 3 | Search for ID 101 | Student record appears |
| 4 | Update ID 101 score to 85 | Score changes to 85 |
| 5 | Search for ID 999 | Student not found |
| 6 | Add another student with ID 101 | Duplicate ID rejected |
| 7 | Enter score 120 | Invalid score rejected |
| 8 | Delete ID 101 | Student record deleted |
| 9 | Display after deletion | Deleted student no longer appears |
